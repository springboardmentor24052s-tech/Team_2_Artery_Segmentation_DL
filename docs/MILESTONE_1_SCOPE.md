# Milestone 1 scope

## In scope
- Project setup and responsive frontend shell
- Demo authentication screens (until backend is connected)
- Case creation, list/history, details, and local demo persistence
- Image upload UI and basic file validation
- Initial preprocessing status/workflow UI
- Dataset/source/annotation review, EDA, architecture, database schema, and wireframes as project documentation

## Out of scope for Milestone 1
- Trained artery segmentation model
- Automated stenosis detection or severity estimation
- Clinical diagnosis or treatment recommendations
- Production-grade authentication, patient-data storage, and deployment

## Honest status labels
The frontend's demo data and simulated status values are for UI demonstration only. They must not be reported as real dataset statistics, preprocessing results, or AI model performance.
